# デザイン用フォント

参照デザインと同じ Zen Maru Gothic（700／900）と Unbounded（600／800）を同梱。
Unbounded.ttf は可変フォントで、描画時にウェイトを指定します。
Google Fonts の公式リポジトリから取得（2026-10-24）。各フォントは同梱の SIL Open Font License に従って再配布します。

- https://github.com/google/fonts/tree/main/ofl/zenmarugothic
- https://github.com/google/fonts/tree/main/ofl/unbounded

画像生成時のダウンロードや、従来の S3 の fonts/ は不要です。ZIP 配布時もこのディレクトリ全体を含めてください。
